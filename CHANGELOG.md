# Changelog

All notable changes are documented here. The project follows semantic versioning for the package and intentional versioning for its contract, policy, capability, and evaluation schemas.

## 0.2.0 — Candidate draft

Evaluation-driven hardening release. Freezes and records 20 controlled cases and
30 real-repository tasks, preserves the unmodified v0.1 baseline, and tightens
the skills and protocol around canonical contract identity, complete patch/status
evidence, validation byproducts, required versus supplemental checks, compact
context transfer, architecture review, and bounded review loops. Agent execution,
workflow state, scheduling, filesystem/git isolation, dependency provisioning,
and integration remain host-owned.

The frozen initial campaign and a separately frozen supplemental correction
campaign are recorded. This remains a candidate draft pending PR review; it is
not a declared completed release. See `docs/roadmap/v0.2/release-evidence.md`.

## 0.1.0 — 2026-08-12

Initial skills-first release with portable orchestration skills, structured task/context/result/review contracts, plan-revision semantics, routing policy, dependency and authorization validation, Codex/Copilot/manual adapters, host-specific doctor diagnostics, evaluation infrastructure, documentation, and CI. Agent execution, workflow persistence, git/worktree management, scheduling, migration runtime, and recovery journals remain host-owned and out of scope.
